# Подготовка к Bitrix Marketplace

## Текущий статус

Подготовка не завершена. Прямое чтение актуальных правил на официальных сайтах было заблокировано сетевой политикой среды (HTTP CONNECT 403). Поэтому здесь нет заявления о том, что актуальные правила изучены, все требования выполнены или модерация гарантирована.

Для продолжения нужны:

1. Точный код решения из карточки Marketplace. Сейчас MODULE_ID — `pv.abandonedcart`, класс установщика — `pv_abandonedcart`. Если в карточке другой код, исправить нужно согласованно весь модуль, пути и точки входа; одной замены строки в архиве недостаточно.
2. Настоящие название разработчика и адрес его сайта. Сейчас сохранено исходное имя `PV Development`, PARTNER_URI пока пуст. Вымышленные реквизиты не подставляются.
3. Доступ к официальной документации. Для `dev.1c-bitrix.ru`, `marketplace.1c-bitrix.ru` и `partners.1c-bitrix.ru` сохранён черновик сетевых настроек; он ещё не применён в выполняющейся среде. Нужны сохранение/применение в настройках среды и повторная проверка доступа.
4. Тестовая установка Битрикс с sale для проверки установки, обновления, удаления, административной темы и реального checkout. В рабочей среде разработки ядра Битрикс нет.

Официальные источники для последующей сверки: [документация разработчика](https://dev.1c-bitrix.ru/), [Marketplace](https://marketplace.1c-bitrix.ru/), [кабинет партнёра](https://partners.1c-bitrix.ru/). Точную ссылку «Документация» из ошибки загрузчика также следует сверить. Эти ссылки перечислены как необходимые источники, а не как уже прочитанные правила.

## Что исправлено и проверено локально

- Явное подключение автозагрузчика модуля после регистрации на чистой установке.
- Повторная установка без дублирования обработчиков и агента; пользовательские сроки хранения сохраняются.
- Проверка прав администратора и сессии для установки и удаления.
- Выбор сохранения данных либо удаления таблицы на втором шаге удаления; заказы, товары и корзины sale не удаляются.
- Языковые файлы установщика ru/en; защита include.php от прямого подключения вне пролога.
- Явное включение сбора контактов, требование отмеченного согласия в форме и дополнительные проверки на сервере.
- Белый список распознанных ORDER_PROP для браузера; неизвестные числовые свойства не отправляются.
- Существующие проверки синхронизации, адреса, контактов, прав доступа, CSRF, экранирования HTML и удаления выбранных записей сохранены.

`tests/installer.php` выполняет реальный установщик с изолированными адаптерами API Битрикс. Это полезная регрессия, но не тест на настоящем ядре/БД. `scripts/check_marketplace.php` проверяет метаданные против явно переданного кода карточки и намеренно сообщает ошибку при незаполненном PARTNER_URI.

## Архив

Ранее выданные `pv.abandonedcart-1.0.x.zip` предназначались для ручной установки: в корне есть каталог `pv.abandonedcart`. Не следует считать их архивами для загрузчика Marketplace. Именно формат подачи, вложенность `.last_version`, требования к версии и реквизитам нужно подтвердить по актуальной документации прежде, чем выпускать архив для модерации. Новый архив с заявлением «готов для Marketplace» пока не сформирован.

Нельзя загружать весь GitHub source archive как дистрибутив: там находятся тесты, скрипты разработки и документация подготовки. В дистрибутив включаются только файлы, необходимые модулю; `.git`, тестовые данные и служебные инструменты не должны попадать на сайт.

## Проверка перед отправкой

После снятия внешних блокировок нужно сверить текущие правила, а затем проверить комплектность описания решения, контакты поддержки, совместимость и требования к версиям, материалы карточки и условия обработки данных. Юридические реквизиты, условия лицензирования и соглашения задаёт разработчик; они не выдумываются автоматически.

На реальном тестовом сайте: чистая установка, обновление сохранённой 1.0.5, отключённый/включённый сбор контактов, неотмеченное/отмеченное согласие, разные типы плательщиков и шаблоны checkout, объединённые JS, смена города/доставки/оплаты, оформление заказа, ручная очистка и оба режима удаления/повторной установки. Итоги этих проверок пока не заявлены как пройденные.
